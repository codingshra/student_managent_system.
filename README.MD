Student Management System

Project Description

The Student Management System is a simple Python project that uses an SQLite database to store and manage student information.

Features

- Add student details
- View all students
- Search students by ID
- Update student information
- Delete student records

Technologies Used

- Python
- SQLite
- VS Code

Database Details

The project uses SQLite to store student information, including:

- Student ID
- Name
- Age
- Course
- Marks

How to Run the Project

1. Install Python on your computer.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the following command:
   
   python student_management.py

5. Select an option from the menu.

Project Structure

student_management_system/
├── student_management.py
├── students.db
└── README.md

Note: The "students.db" file is created automatically when you run the program.
